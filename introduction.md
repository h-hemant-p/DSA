# Introduction to DSA

---

**Data Structure**  is A way of organizing and storing data efficiently and **Algorithm**  is A step-by-step procedure to solve a problem.

##### Why DSA?

- **Efficiency**: Optimized problem-solving.
- **Scalability**: Handles large-scale data.

##### Types of Data Structures

- **Linear**: Array, Linked List, Stack, Queue
- **Non-Linear**: Tree, Graph, Hash Table

##### Types of Algorithms

- **Searching**: Linear Search, Binary Search
- **Sorting**: Bubble Sort, Merge Sort, Quick Sort
- **Recursion**: Function calling itself
- **Dynamic Programming (DP)**: Optimizing subproblems
- **Greedy Algorithm**: Making optimal choices at each step

##### Common DSA Applications

- **Databases**: Indexing, Searching
- **Operating Systems**: Scheduling
- **AI/ML**: Graphs, Trees, DP
- **Web Development**: Caching, Hashing
